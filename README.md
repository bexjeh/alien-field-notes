A one-line review of planet Earth written by an alien tourist, entered in the make.fun bounty "Alien Field Notes: The Two Day Earth Review". The program writes a single original line of plain text (1–200 characters) to `entry.txt` — deterministic, standard library only, no network, no clock, no randomness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
